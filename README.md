TodoApp - приложение для списка дел
Пользователь должен иметь возможность
авторизоваться в системе с помощью Bearer token
добавить дело
удалить дело
редактировать дело
получить список дел на определенную дату
иметь возможность фильтровать дела по признаку - завершено/не завершено/все

Все операции со списками дел должны быть доступны только тем пользователям, которые их создали

Зачем нужен редис ?
при авторизации для пользователя создается токен, который должен быть активен в течении заданного промежутка времени, пока токен активен мы можем получить его из редиса и получить по нему информацию о пользователе

Зачем нужен postgres
в постгрес мы храним информацию об аккаунте пользователя, сами списки дел

Развертывание сервиса
Все сервисы должны запускаться одной командой docker compose
